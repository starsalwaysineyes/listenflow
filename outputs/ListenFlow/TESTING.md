## 0.1.0 音频与问答链路

- 编译：Swift 原生应用构建通过。
- 本机模型：Qwen3-ASR 1.7B，MLX Audio 0.5.5。
- 真实音频链路：独立测试播放器 → ScreenCaptureKit 指定 App 音频 → 16kHz 转换 → 本地 ASR → SwiftUI。
- 音频样本：本机既有 27.16 秒中文合成语音，不是真实会议。
- 实际生成 7 段转写；从每段开始采集到文字返回，最短 4.31 秒、平均 4.36 秒、最长 4.43 秒。
- 音源隔离：测试播放器停止后，使用另一个进程播放 6 秒语音，转写仍保持 7 段。
- 麦克风关闭：全程保持关闭，未请求麦克风权限，所有段落均来自选定 App。
- 上下文问答：在转写仍开启时，通过应用向 DeepSeek Flash 提问，流式返回正确答案和时间戳。
- 自动保存：会话 JSON 中的转写和问答均已保存。
- 核心测试：静音、切片边界、停顿、双音源分离、丢弃缓存、上下文快照、JSON 往返测试通过。
- 接口测试：本地模拟 SSE 经原生 URLSession 验证通过；DeepSeek 模型列表、一次独立 API 调用及应用内真实问答均通过。
- 凭证检查：项目源码未包含 API Key。密钥通过标准输入写入应用自己的 macOS 钥匙串项。
